# Web Development Assessment

This repository contains the exercises completed for the Web Development Set Exercises assessment (CCO4007).

## Exercises

| Folder | Topic |
|--------|--------|
| `01-semantic-markup` | Semantic HTML recipe page |
| `02-css-styling` | External CSS styling |
| `03-page-layout` | CSS Grid, float, video |
| `04-web-accessibility` | ARIA, skip link, accessibility |
